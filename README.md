# 🎮 ApertureLauncher v1.0 (Локальный Стим для пираток)

**ApertureLauncher** — это легковесный, автономный игровой менеджер и лаунчер, разработанный на чистой Java (Swing) без использования сторонних графических библиотек. Программа создана в рамках исследовательских тестов Лаборатории Aperture Science.

---

## 🛠️ Основные возможности

* **Локальная база данных** — лаунчер вечно хранит список ваших добавленных игр в текстовом файле `pirate_steam_db.txt` прямо на вашем жестком диске.
* **Универсальный запуск** — поддержка быстрого запуска любых исполняемых файлов в формате `.exe` и `.bat` в один клик.
* **Автоматическое имя** — система сама распознает имя исполняемого файла и предлагает его в качестве названия карточки.
* **Процедурная озвучка** — встроенная звуковая подсистема генерирует аналоговые ретро-писки Aperture при взаимодействии с интерфейсом прямо из кода, без внешних аудиофайлов.
* **Интерфейс в стиле Steam** — строгий темно-синий дизайн, имитирующий карточки реальной игровой библиотеки.

---

## 📦 Как установить и протестировать

1. Скачайте файл **`ApertureLauncherSetup.exe`** из этого репозитория.
2. Запустите установщик (он выполнен на классическом ретро-движке Inno Setup с оригинальной иконкой диска и синего монитора).
3. После завершения установки запустите лаунчер с Рабочего стола.
4. Нажмите кнопку **`+ Добавить пиратку`**, выберите путь к любой вашей игре (например, `portal2.exe`) и нажмите кнопку **`ИГРАТЬ`**.

---

## ⚙️ Требования для компиляции исходников

Если вы хотите запустить проект из исходного кода:
* Установленная Java (JDK 8 или выше)
* Компиляция: `javac ApertureLauncher.java`
* Сборка в автономный JAR: `jar cfe ApertureLauncher.jar ApertureLauncher *.class`
